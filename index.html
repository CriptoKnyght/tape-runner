    How this works
    Indicators come from your real bot/ code, computed by replay.py. The lab re-runs the bot's decision rules in the browser (game/sim.js). With default settings it matches the Python replay trade for trade; node game/verify_sim.js checks that.
    Changed the bot's code itself (a new check, new logic)? Run python replay.py --label "My change" --out game/my_change.json, then load it and pick Python replay (locked).
    Maps run from 6 hours to a full day of 1-minute candles. Fills happen at the bar close with a 0.045% fee per side. Settings you tune until they win on one map usually just fit that map's noise, so always test them on the other maps.
